# Granthalay API

Granthalay API is the privacy-first modular Spring Boot backend for
[Granthalay](https://github.com/SamsterZero/Granthalay), a local-first EPUB library and offline PWA.
It provides optional accounts, catalog, commerce, entitlements, publisher operations, and secure
book delivery while personal books and reading activity remain on the reader's device by default.
