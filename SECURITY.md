# Security Policy

## Supported versions

Granthalay API is under active development. Security fixes are provided on the latest `main` branch
and, once releases are published, the latest release only.

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/SamsterZero/granthalayapi/security/advisories/new).
Do not open a public issue for suspected authentication bypass, broken access control, entitlement
bypass, injection, secret exposure, unsafe file delivery, payment manipulation, or dependency
vulnerabilities.

Include the affected commit or version, impact, reproducible steps, and suggested mitigation if
known. Use synthetic data and do not include real credentials, payment information, personal data,
or copyrighted books.

## Response targets

- Initial acknowledgement: within 7 days
- Triage: within 14 days
- Status update: at least every 14 days while remediation is active

Please allow coordinated remediation before public disclosure.
